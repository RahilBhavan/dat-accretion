# Documentation index

This page lists every file in `docs/` and what each one tells you. Start with the overview.

| file | read it for |
|---|---|
| [`overview.md`](overview.md) | what the project does, what it produces and how the code turns filings into the page |
| [`methodology.md`](methodology.md) | the definitions, formulas and labeled estimates, for a reader checking the numbers |
| [`memo.md`](memo.md) | the one-page memo: break-even prices, weekly counts and value to common by cause |
| [`memo.html`](memo.html), [`memo.pdf`](memo.pdf) | the same memo, as printed from HTML with headless Chrome |
| [`map.svg`](map.svg) | the memo's break-even map, net mNAV m against preferred price q |
| [`decisions.md`](decisions.md) | every decision that shapes the code or the numbers, why, and what it replaced |
| [`how-it-was-made.md`](how-it-was-made.md) | the build in order: the plan, each step, what it found and how the result differs from the plan |
| [`build-notes.md`](build-notes.md) | problems hit while building and what they did to the numbers |
| [`reader-test.md`](reader-test.md) | the 2026-10-08 first-screen reader test and the protocol for a human test |
| [`design-improvement-prompt.md`](design-improvement-prompt.md) | the brief given to an agent for the graph and information design pass |
| [`course/`](course/README.md) | a 24-lesson course that teaches the project from scratch, with quizzes |

`memo.md`, `memo.html` and `map.svg` are generated by `python -m dat.memo`. Edit `dat/memo.py`, not the files.
